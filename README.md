# qt-ship-navigation-project
A small Qt vessel navigation project with MongoDB ship and route saving and a cell grid system.

Instructions:
This project needs MongoDB, MapLibre, OSM's polygons.
https://osmdata.openstreetmap.de/data/water-polygons.html
Water polygons can be downloaded from here and put inside the navigation_data file. There are some of them inside navigation_data but an updated version would be better from this link.
Others can be downloaded with sudo.
Used Qt 6.11
